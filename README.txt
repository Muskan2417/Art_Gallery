Heritage Fame Art Gallery

1. Open WebApplication7.sln in Visual Studio.
2. Build > Clean Solution.
3. Build > Rebuild Solution.
4. Run with Ctrl+F5.
5. The application creates/updates the LocalDB database HeritageFameArtGallery on startup.
6. Supplied catalog images are synchronized by ImageUrl; existing order history is preserved.
